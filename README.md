
# Hi, I'm Bhavika.

Software Engineer interested in backend systems, AI, and the engineering behind intelligent software.

Over the past few years, I've built software in both biotech and fintech, working on systems where correctness matters as much as performance. From scientific data platforms and secure data access to payment workflows and financial systems, I've learned that reliability is rarely an optional feature.

Most of my time is spent understanding how things work beneath the abstraction. LLMs, databases, distributed systems, retrieval, operating systems, compilers. I enjoy learning from first principles because abstractions are useful until they leak.

I like building systems that are easy to reason about. The interesting engineering usually starts after the prototype works.

## Currently exploring

* Large Language Models
* Agentic AI
* Retrieval-Augmented Generation
* Information Retrieval
* Distributed Systems
* Database Internals
* System Design
* Performance Engineering

## What I optimize for

* Correctness before optimization.
* Simple architectures that remain simple as they grow.
* Systems that are observable, debuggable, and resilient.
* Understanding trade-offs instead of chasing patterns.

## A few things I believe

* Every layer of abstraction hides an implementation worth understanding.
* Simple systems are usually the result of difficult engineering.
* Production is the only environment that never reads the documentation.
* Most engineering problems become simpler once the problem statement becomes precise.
* The goal is not clever code. The goal is code that still makes sense six months later.

> "Curiosity scales better than certainty."
