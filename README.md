👩‍💻 A little about me
I'm a software engineer based in Bengaluru, with experience building backend-heavy, data-intensive software across biotech and fintech. My professional work spans scientific workflows, APIs, database-driven systems, React applications, and reliability-focused automation.

Outside work, I build end-to-end AI systems, especially where the interesting problems start after an LLM returns a response: retrieval quality, orchestration, evidence, state, evaluation, failure handling, and whether the output is actually useful.
- 🧠 Current focus: Applied AI, agentic workflows, RAG, context engineering, and inference/system performance.
- ⚙️ Engineering mindset: Understand the failure modes. Make the trade-offs explicit. Keep it observable.
- ✍️ Learning in public: I write about generative AI from first principles and document my experiments.
- 🎯 What I care about: Turning a real problem into a working, dependable product — not stopping at the demo.
